# Configuración y perfiles

Configuración aparece en el menú para cada perfil autenticado. Reutiliza las pantallas y los permisos existentes, sin duplicar gestión de usuarios, turnos ni contraseñas.

- Administración: enlaces a usuarios, permisos, centros, servicios, turnos y calendario/apertura.
- Recepción: clientes, calendario, turnos, productos/pagos, caja y fichajes del equipo con identificación de quien los registra.
- Entrenador: agenda y clientes vinculados, rutinas, turnos propios, fichajes, ausencias y recuperaciones.
- Cliente: reservas propias y cambio de contraseña.

Cada pantalla explica los permisos y límites del perfil conectado. No es un editor de permisos individuales: administración asigna los perfiles existentes desde Usuarios. El servidor mantiene las restricciones de cada operación; esconder un enlace no sustituye a esas comprobaciones.

Las cuentas locales de prueba creadas para esta revisión están identificadas con `.prueba`. Requieren cambiar la contraseña al primer acceso. Sus credenciales se entregan al solicitante y no se guardan en el repositorio. Estas cuentas pertenecen a la base de datos local: hacer push del código no las crea en otros ordenadores.

Recuperaciones utiliza ahora tarjetas separadas, márgenes propios, botones adaptados a móvil y un botón Actualizar. Próximas sesiones excluye fechas anteriores al día actual del centro. La política de recuperación no se ha modificado.
